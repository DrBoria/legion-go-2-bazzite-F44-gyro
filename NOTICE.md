# Attribution

This project contains a modified build of InputPlumber.

InputPlumber is an open-source input routing and control daemon for Linux
developed by the InputPlumber contributors.

The original upstream repository is recorded in `SOURCE_UPSTREAM`.

The exact upstream source revision used for this build is recorded in
`SOURCE_BASE_COMMIT`.

The source modifications are provided in:
patches/inputplumber-legion-go-2-bazzite.patch

This project is unofficial and is not affiliated with or endorsed by
Lenovo, Valve, SteamOS, Bazzite, or the InputPlumber maintainers.

## AI Assistance

This project, including its code modifications, documentation, installation
scripts, and repository structure, was created with the assistance of
artificial intelligence.

All generated content was reviewed, tested, and validated manually on a
Lenovo Legion Go 2 running Bazzite (Fedora 44).
